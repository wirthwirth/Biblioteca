# Biblioteca

Projeto de estudo em Java para praticar Programação Orientada a Objetos. Roda no console e vou evoluindo conforme aprendo novos conceitos.

## O que faz hoje

- Cadastra livros (nome, autor, páginas e disponibilidade).
- Guarda os livros no acervo da biblioteca.
- Lista os livros mostrando se estão disponíveis ou não.
